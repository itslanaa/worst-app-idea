An app that tracks how many steps your smart fridge takes, with a leaderboard for appliances and a premium plan for the toaster.

## How it works

Run `main.ts` with Node.js. It writes the one-sentence pitch to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).

```sh
MAKEFUN_OUTPUT_DIR=/tmp/wa-out node main.ts
```

The entry is 134 characters, within the 1–240 character gate.
